# 男蜜-だんみつ-鹿児島店 予約サイト

予約サイトと管理画面です。

- 予約サイト: `index.html`
- 管理画面: `admin/`

## パソコンで使う（予約の受付・保存ができます）

```bash
node server.js
```

- 予約サイト http://localhost:8793/
- 管理画面 http://localhost:8793/admin/

## GitHub Pages で見る（デモ表示）

サーバーがないため、予約は店舗へ送信されず、管理画面の変更も保存されません。見た目と操作の確認用です。

## エステ魂の出勤を取り込む

管理画面の「エステ魂」タブで、エステ魂の店舗ログイン用メールアドレスとパスワードを保存すると、エステ魂の出勤表（今日から14日分）をこのサイトの出勤に取り込みます。

- エステ魂は**読むだけ**です。エステ魂の内容は変更しません。
- `node server.js` が動いている間、10分ごとに自動で取り込みます（タブでオン・オフできます）。「今すぐ取り込む」ボタンもあります。
- エステ魂のセラピストは、名前が同じ人と自動でつなぎます。いない人は写真・年齢つきで新しく追加します。
- つながったセラピストの出勤は、エステ魂の内容で上書きされます。エステ魂で ×・TEL の時間は予約サイトで選べません。
- このサイトで「確定」にした予約の時間は、取り込んだ後も × のままです。
- ログイン情報は `data/estama.json` にだけ保存されます（GitHub には上がりません）。
- Node.js 18 以上が必要です。
